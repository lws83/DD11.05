# DD11.05 稳定性诊断版

## 目的

此版本是用于定位注入后启动兼容性问题的最小诊断构建。它只在目标进程加载时记录 Bundle ID、应用版本、构建号和 iOS 版本。

## 有意移除的行为

本版本不再 Hook 或改写：

- 文件与目录查询、资源读取和 URL scheme 查询；
- 进程环境、动态库列表和设备标识；
- 越狱/调试/安全环境检测结果；
- 微信检查、上报、联系人验证或请求上下文；
- 崩溃采集、安全模式和登录/前后台生命周期方法。

这些改动是为了避免伪造系统状态、吞掉错误、破坏业务数据或阻断原有监控流程。原始 ZIP 应保留作为备份。

## 构建

需要已配置 Theos 的 macOS 环境：

```sh
make clean
make package FINALPACKAGE=1
```

Rootless（按你的 Theos 环境支持情况）：

```sh
make clean
make package THEOS_PACKAGE_SCHEME=rootless FINALPACKAGE=1
```

## 验证建议

1. 先在测试设备和测试账号上安装。
2. 观察应用冷启动、登录、前后台切换和网络请求是否正常。
3. 查看设备日志中的 `[DD11.05]` 启动记录。
4. 若出现崩溃，记录崩溃时间、iOS 版本、应用版本和完整崩溃日志；不要仅凭“已加载”判断功能正常。

## 限制

当前交付为源码包。执行环境没有 Theos/iOS SDK，因此尚未完成实际编译、签名或设备验证。CI 工作流仍需在 GitHub Actions 中运行确认。
